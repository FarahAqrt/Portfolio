Connect to GitHub

To publish changes, this page needs a GitHub access token — a password-like key for your account. It's saved only in this browser (localStorage) and used only to talk directly to GitHub's API. It is never sent to me or anyone else.

  1. Open github.com/settings/personal-access-tokens/new
  2. Resource owner: FarahAqrt. Repository access: Only select repositories → Portfolio
  3. Under Permissions → Repository permissions, set Contents: Read and write
  4. Generate the token and paste it below
